# Mi Proyecto Digital - Landing Page Básica

## Descripción
Este proyecto consiste en una landing page sencilla desarrollada como parte del Trabajo Práctico Integrador para demostrar el flujo de trabajo básico con Git y GitHub.

## Objetivo
Organizar, documentar y versionar un sitio web básico aplicando buenas prácticas de control de versiones.

## Estructura del repositorio
- `README.md`: Documentación general del proyecto.
- `ENTREGA.md`: Registro del proceso de trabajo y entrega del TP.
- `proyecto/`: Carpeta con el código fuente (HTML y CSS).
  - `proyecto/index.html`: Estructura principal del sitio.
  - `proyecto/styles.css`: Estilos visuales del sitio.
